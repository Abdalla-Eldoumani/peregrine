# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability
reporting: open the repository's **Security** tab and choose **Report a
vulnerability**. Do not open a public issue for a suspected vulnerability.

Include the Peregrine version, how you installed it (Release wheel or a source
build, CPU-only or CUDA), your platform, and the smallest input that shows the
problem.

## Supported versions

Fixes land on the latest release. Peregrine is a single-maintainer project, so
older versions are not patched.
